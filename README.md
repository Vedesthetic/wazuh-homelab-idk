# 🛡️ Wazuh SIEM Homelab

A hands-on cybersecurity homelab built using **Wazuh SIEM** to learn centralized log collection, security monitoring, and custom threat detection on Linux systems.

---

## 📖 Overview

This project demonstrates the deployment and configuration of a Wazuh Security Information and Event Management (SIEM) environment for monitoring Linux systems.

The homelab focuses on collecting authentication logs, creating custom detection rules, and analyzing security events through the Wazuh Dashboard.

---

## ✨ Features

- Centralized log collection
- Real-time security monitoring
- Custom SSH authentication detection rules
- Alert generation and visualization
- Linux authentication log analysis
- Hands-on SIEM practice

---

## 🛠️ Tech Stack

- Wazuh SIEM
- Ubuntu Server
- Docker
- Linux
- XML
- SSH
